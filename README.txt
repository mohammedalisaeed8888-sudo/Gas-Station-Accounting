نظام حسابات محطة الغاز — نسخة أولية قابلة للتشغيل

المحتويات:
- index.html: واجهة التطبيق.
- schema.sql: إعداد قاعدة البيانات.
- manifest.webmanifest: تعريف التثبيت كتطبيق موبايل.

تشغيله على تلفونين:
1) أنشئ مشروعاً في Supabase.
2) نفّذ schema.sql في SQL Editor.
3) انسخ Project URL و anon/public key من إعدادات API.
4) افتح التطبيق وأدخل بيانات الربط، ثم أنشئ حساب بريد وكلمة مرور.
5) استخدم نفس الحساب على تلفوني مجد وعمر.
6) ارفع الملفات على استضافة HTTPS مثل Netlify أو Vercel أو GitHub Pages، ثم افتح الرابط من الهاتفين واختر Add to Home Screen.

لا تستخدم service_role key. استخدم anon/public key فقط.

معادلات الحساب:
اللترات = مجموع (قراءة النهاية - قراءة البداية) للطرمبات الثلاث.
المبيعات = اللترات × سعر اللتر.
الكاش المفترض = المبيعات - الديون الآجلة - المصروفات - مدفوعات المحافظ.
المحافظ المفترضة = مبالغ المحافظ المستلمة من زبائن الوردية.
فرق الحساب = (الكاش الفعلي + المحافظ الفعلية) - (الكاش المفترض + المحافظ المفترضة).

ملاحظات:
- يبدأ كل عامل من صفر نقدياً كما اتفقنا.
- المصروفات الافتراضية في كل نموذج وردية: صرفة العامل 2350، ومندوب شركة النفط 4000. راجعها قبل الحفظ وسجل ما صُرف فعلياً.
- الديون تسجل كمبيعات آجلة، ولا تعد نقداً مستلماً.
- المحافظ المسجلة هي تحصيلات الزبائن خلال الوردية فقط، لا رصيد المحفظة السابق.
- اختبر التطبيق بأرقام تجريبية قبل استخدامه في الحسابات الفعلية.
